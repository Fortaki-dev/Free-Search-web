FreeSearch (Frosya)

Мощное десктопное и мобильное приложение для быстрого поиска информации с встроенным ИИ-помощником, играми, консолью и другими полезными инструментами. Работает полностью локально.

Скачать для Windows (.exe) Скачать для Android (.apk)

Файлы скачиваются напрямую из официальных релизов на GitHub. Автор рекомендует проверить их на VirusTotal перед запуском.

Характеристики версий

FreeSearch 1.15.10WIN

Windows • Последняя
  • Платформа: Windows 7 / 8 / 10 / 11 (x64)
  • ИИ-помощник: Frosya (GPT-2), локальные модели
  • Защита: Google Safe Browsing, ByeDPI
  • Инструменты: Игры (Змейка, Тетрис), консоль, переводчик, виджеты
  • ОЗУ: 2 ГБ (рекомендуется 4 ГБ)
  • Место на диске: ~500 МБ (с папкой AI)
  • Установка: Inno Setup, один .exe без Python

FreeSearch 1.13w1a

Android • Стабильная
  • Платформа: Android 8.0+ (API 27)
  • Поиск: Wikipedia, DuckDuckGo (встроенный браузер)
  • Медиа: Плавающий видеоплеер (YouTube, Rutube, VK)
  • Кастомизация: Градиенты, загрузка фонов (изображения/GIF), тёмная/светлая тема
  • Профиль: Сохранение имени и аватара
  • Виджеты: Добавление сайтов в виде плиток
  • Пасхалки: Секретное слово «кутман»
Ключевые возможности
Умный поиск — одновременно по DuckDuckGo и Wikipedia с AI-ответами от Frosya (GPT-2)
Чат с Frosya — задавайте любые вопросы, история сохраняется
Консоль с играми — «Змейка», «Тетрис», калькулятор и мировые часы
Переводчик — русский, английский, кыргызский и автоопределение
Виджеты — добавляйте любые сайты в виде плиток на главный экран
Настройки внешности — темы, фоновые изображения, акцентные цвета
Встроенная защита — интеграция с Google Safe Browsing API
Автономная работа — всё упаковано в один .exe/.apk, не требуется Python или браузер
Системные требования
  • Windows: Windows 7 / 8 / 10 / 11 (64-бит)
  • Android: Android 8.0+ (требуется разрешение на установку из неизвестных источников)
  • ОЗУ: 2 ГБ (рекомендуется 4 ГБ для работы AI-моделей)
  • Место на диске: ~500 МБ (с учётом папки AI)
